# Agent Skills

This repository is equipped with specialized engineering and productivity skills.

## Available Skills

- **diagnose**: Disciplined diagnosis loop for hard bugs.
- **grill-with-docs**: Challenges plans against the domain model and updates docs.
- **improve-codebase-architecture**: Finds refactoring and deepening opportunities.
- **setup-matt-pocock-skills**: Configures the issue tracker and triage context.
- **tdd**: Test-driven development red-green-refactor loop.
- **to-issues**: Breaks plans/specs into independently-grabbable issues.
- **to-prd**: Turns conversation context into a PRD.
- **triage**: Manages issue workflow through a state machine.
- **zoom-out**: Provides broader context and higher-level perspectives.
- **caveman**: Ultra-compressed communication mode.
- **grill-me**: Relentless interviewing to reach shared understanding.
- **write-a-skill**: Tool for creating new structured agent skills.

## Agent skills

### Issue tracker
Tracked using the Anigma `td` CLI tool and local markdown files in `docs` and `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels
Standard labels mapped to canonical roles. See `docs/agents/triage-labels.md`.

### Domain docs
Multi-context layout using `CONTEXT-MAP.md` and `anigma/Docs/ADR/`. See `docs/agents/domain.md`.
