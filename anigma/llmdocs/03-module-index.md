# Module Index

## Core Libraries
- `AnigmaFoundation`, `AnigmaCore`, and `AnigmaPrimitives` are foundational libraries listed in `Package.swift`.
- Governance and storage pillars include `ContractsCore`, `DatabaseCore`, `GovernanceCore`, `StorageCore`, `TelemetryCore`, and `ExecutionCore` in `Package.swift`.
- Platform-facing libraries include `PlatformCore`, `AnigmaClientKit`, `AnigmaHostKit`, `AnigmaHostMac`, and `AnigmaSystemSpine`.

## Capability and Domain Modules
- Core capability modules include `HarmoniaModule`, `DiaplasionModule`, `AccessumModule`, `OutlineumModule`, `ContextumModule`, and `CathedralModule` as defined in `Package.swift`.
- Additional modules include `ArtifactStoreModule`, `DevelopumModule`, `ModelRegistryModule`, `VectorumModule`, and `ObservatoriumModule` in `Package.swift`.
- AI and agent features are composed from `AnigmaAgents` and `AnigmaAIConsole` in `Package.swift`.

## Capsules and Toolkits
- Capsule-style libraries include `TextChunkingCapsule`, `VectorCapsule`, `VizAggregationCapsule`, and `RenderPlanCapsule` from `Package.swift`.
- Supporting toolkits include `DocumentIRKit`, `DocumentRenderKit`, `TypographyKit`, and `VectorOpsKit`.

## Executable Targets
- Primary executables are `anigma`, `anigma-cli`, `anigma-app`, `anigmad`, and `anigma-mcp` as declared in `Package.swift`.
- Additional tools include `harmonia-surface`, `doctrine`, `diaplasion-pipeline`, and `ml-worker`.
