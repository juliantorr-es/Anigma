## 📚 How to Use This System

### For Developers

**Before Committing**:
```bash
# Run contract checks
./Scripts/ci/check-design-tokens.sh
./Scripts/ci/check-accessibility.sh

# Fix violations
# Use Docs/ManualReviewGuide.md
```

**Writing New Code**:
1. Use `Bauhaus.*` tokens (never raw values)
2. Add `.accessibilityLabel()` to interactive elements
3. Use `.primaryButtonStyle()` for buttons
4. Return `OperationResult<T>` for async operations

### For Reviewers

**PR Checklist**:
- [ ] CI gates passing
- [ ] No new contract violations
- [ ] Design tokens used consistently
- [ ] Accessibility labels present
- [ ] Tests passing
