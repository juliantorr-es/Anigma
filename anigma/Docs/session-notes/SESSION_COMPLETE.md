## 🎓 Best Practices Established

### Accessibility
1. **Icon buttons**: Always `.accessibilityLabel("Action name")`
2. **Text fields**: Label + hint
3. **Toggles**: Label + hint (if non-obvious)
4. **Pickers**: Label + hint
5. **Selection buttons**: `.accessibilityAddTraits([.isSelected])`
6. **Dynamic content**: Use interpolation in labels
7. **File/folder lists**: Include type in label
8. **Menu items**: Include context (e.g., source name)
9. **Destructive actions**: Always include hints
10. **Complex rows**: Use `.accessibilityElement(children: .combine)`

### Contract Enforcement
1. **Semantic tokens** - Always use `Bauhaus.*` tokens
2. **OperationResult** - For all async operations
3. **AnigmaError** - Stable error codes
4. **Button styles** - Standardized `.primaryButtonStyle()` etc.
5. **Performance budgets** - Hard latency limits
6. **Continuous enforcement** - CI gates always on
