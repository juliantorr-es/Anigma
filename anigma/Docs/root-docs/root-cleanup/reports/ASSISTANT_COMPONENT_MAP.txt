# Assistant Analysis Surface - Component Map

## File Dependencies

    ├─ Imports: SwiftUI
    ├─ Uses: AssistantState (@StateObject)
    ├─ Uses: AnalysisCanvasView (conditional)
    ├─ Uses: Bauhaus design system
    └─ Components:
        ├─ RecentAnalysisRow
        └─ ContextSummaryCard

AnalysisCanvasView.swift
    ├─ Imports: SwiftUI
    ├─ Uses: AssistantState (@ObservedObject)
    ├─ Uses: ProvenanceView (conditional)
    ├─ Uses: Bauhaus design system
    └─ Components:
        ├─ AnalysisResultCard
        ├─ ComputeStatusCard
        ├─ SourcesDisclosureGroup
        └─ SourceReferenceRow

ProvenanceView.swift
    ├─ Imports: SwiftUI
    ├─ Uses: Analysis (model)
    ├─ Uses: Bauhaus design system
    └─ Components:
        ├─ ProvenanceSourceCard
        ├─ ReceiptCard
        ├─ TimelineView
        └─ TimelineEvent

AssistantState.swift
    ├─ Imports: SwiftUI, Combine
    ├─ @MainActor class
    └─ Models:
        ├─ Analysis
        ├─ AnalysisPhase
        ├─ AnalysisResult
        ├─ SourceReference
        ├─ Receipt
        └─ ComputeStatus

## UI Flow

Home State (Calm)
    │
    │ User enters query
    │ User presses Enter or clicks arrow
    │
    ├─► AssistantState.startNewAnalysis()
    │   ├─ Phase: preparing
    │   ├─ Phase: computing
    │   └─ Phase: complete
    │
    └─► Transition to Canvas State
        │
        ├─ Show results
        ├─ Show compute status
        ├─ Show sources (collapsed)
        │
        └─ Optional: Show provenance panel
            ├─ Verification badge
            ├─ Source chain
            ├─ Receipts
            └─ Timeline

## Isolation Strategy

✓ New files in Surfaces/ directory
✓ New state in Model/ directory
✓ No changes to existing views
✓ No changes to daemon/admin surfaces
✓ No backend dependencies
✓ Uses existing design system
