## Implementation

### Script Created: `Scripts/validate_xcodebuild_debug.sh`

```bash
#!/bin/bash
set -euo pipefail

# Features:
# - Strict bash mode
# - Repo-root detection
# - Supports workspace (package.xcworkspace)
# - Uses Debug configuration
# - Uses stable DerivedData path (.build/xcode-derived-data)

```

## _NumericsShims Determination

**Answer:** ❌ **_NumericsShims does NOT block xcodebuild Debug**

**Evidence:**
- All 4 foundation/runtime schemes built successfully with xcodebuild Debug
- `swift-numerics @ 1.1.1` was present in resolved dependencies for all builds
- AnigmaPipeline scheme transitively includes MediaCore (which has Metal, CoreVideo, VideoToolbox dependencies)
- No linker or compiler errors related to _NumericsShims

**Conclusion:** The _NumericsShims issue is **specific to the `swift build` command-line tool**, not a fundamental blocker of the Xcode build system. xcodebuild resolves and builds targets successfully even with swift-numerics in the dependency graph.

**Priority change:** _NumericsShims is now a **SwiftPM/tooling cleanup task (LOWER PRIORITY)**, not a foreground build blocker.
